Synthetic organism metric — Lucy density. Hard Acc = argmax accuracy. Acc keep % = this Hard Acc ÷ Acc-champ Hard Acc (100% = matches the best Acc on the board). Lean = Acc keep ≥95%, then smallest RAM / fastest Thru / best Avail — sacrifice peak Acc only inside that band. Availability is infer/(infer+train): SGD that blocks the live loop dies here.
